01 — Measurement

It was never a theming problem

The machine was being throttled by its own CPU governor. A performance governor with energy_performance_preference=performance on a 15 W laptop chip: it jumped to maximum turbo for trivial work, exceeded its thermal headroom in milliseconds, was cut by PROCHOT, recovered and repeated. 24,440 times in one boot, while idle.

The missing middle gear is the signature. Dell Latitude 5400, i7-8665U, UHD 620. No hardware was changed; the fix is script 01.

Check your own machine before blaming anything else

cat /sys/devices/system/cpu/cpu0/thermal_throttle/package_throttle_total_time_ms
cat /sys/devices/system/cpu/cpu0/cpufreq/energy_performance_preference

A non-zero first value that keeps climbing while the machine is idle, together with performance in the second, is the fault this project fixes.

Spot temperature readings lie. Sampling sensors every two seconds showed a comfortable 61–68 °C while the CPU was throttling a quarter of the time. The samples were landing in the valleys between millisecond spikes. Trust the cumulative counters, not the thermometer.

02 — Appearance

What changes on screen, keyed to the setting that changes it

Two schematic diagrams of the same desktop. Every numbered difference is produced by a specific gsettings or dconf key written by scripts 03 and 04; the list below names each one.

  1. Window controls

    Stock button-layout is appmenu:close: one close button, on the right. Script 03 sets close,minimize,maximize:, and WhiteSur draws the three as red, amber and green.

  2. Header bar and widgets

    gtk-theme becomes WhiteSur-Dark; the shell theme of the same name is applied through the user-themes extension. Note that GTK4/libadwaita applications follow this only where the theme provides a libadwaita stylesheet.

  3. Corner radius

    libadwaita rounds its own windows; GTK3, Electron and Qt windows keep square bottom corners. The rounded-window-corners extension rounds all of them, so every window on screen matches.

  4. Fonts

    font-name becomes Inter 11 and titlebar-font becomes Inter Semi-Bold 11, replacing Adwaita Sans. Hinting slight, RGBA antialiasing.

  5. Top bar

    blur-my-shell with panel/static-blur on: translucent, blurred once against the wallpaper rather than every frame, which is what a UHD 620 can afford.

  6. Dock

    Stock GNOME shows the dash only inside the Activities overview. dash-to-dock pins it to the bottom: 48 px icons, dot running-indicators, dynamic transparency, auto-hide with intellihide.

Why diagrams and not screenshots. GNOME Shell on Wayland only permits screen capture through the interactive portal, and GTK4/libadwaita applications ignore GTK_THEME, so an honest stock-versus-themed pair of the same window cannot be produced by a script. These are drawn to the settings the scripts write, in the page's own palette, and claim nothing more than that.

03 — Scripts

Ten scripts, each one reversible

Numbered, ordered, independently runnable. Every one is safe to run twice.

  1. 00

    Preflight

    Backs up your entire dconf, then prints a hardware and thermal baseline. Run it first so you can always get back.

  2. 01

    Performance

    The one that matters. Removes forced-performance tuning, restores power-profiles-daemon, sets a sane governor and energy policy.

  3. 02

    Packages

    dnf speed config, RPM Fusion, full ffmpeg, hardware video decode, backup tooling.

  4. 03

    Theme

    WhiteSur GTK, shell, icons and cursors. Inter and JetBrains Mono. Wallpaper and macOS system sounds.

  5. 04

    Extensions

    Twelve GNOME extensions from extensions.gnome.org, tuned for a weak integrated GPU.

  6. 05

    Shortcuts

    macOS-style keybindings using nothing but GNOME settings. No daemon required.

  7. 06

    keyd optional

    Super becomes Cmd in every application, without breaking Ctrl+C in your terminal.

  8. 07

    Voice

    Replaces formant-synthesis espeak-ng with Piper neural TTS, entirely inside your home directory.

  9. 08

    Snapshots

    btrfs safety net via snapper, wired into dnf so every transaction is undoable.

  10. 09

    Verify

    Read-only end-to-end check. Reports what actually took effect, and what silently did not.

05 — Clipboard

Cmd+C that does not break your terminal

Remappers normally turn Super+C into Ctrl+C, which in a terminal is SIGINT. You end up choosing between copy and interrupt. The way out is to never send Ctrl+C at all.

  1. keyd emits a media key

    XF86Copy, XF86Paste, XF86Cut, not Ctrl combinations.

  2. Applications handle it natively

    GTK and Qt already treat those keys as clipboard actions. Nothing to configure.

  3. Ctrl+C is untouched

    It is never transmitted, so interrupt keeps working exactly as before.

07 — Notes

Things that cost real debugging time

Each is written up in the repository with the diagnosis that actually worked.

  • “Enabled” is not “running”

    A GNOME extension can sit in the enabled list reporting OUT OF DATE and silently never load. Check State, not the list.

  • keyd layers inherit

    Omitting a key from a compound layer does not pass it through; it falls back to the parent layer and fires the wrong thing.

  • Never grep for “error”

    keyd check reports success as “No errors found.” A naive grep marks a valid config broken.

  • The wrong piper

    The piper package in Fedora’s repositories is a gaming-mouse tool. Piper TTS is not packaged for Fedora at all.

  • pkill -f kills you

    pkill -f speech-dispatcher matches the calling shell’s own command line and ends your session.

  • Fractional scaling costs

    It renders large and downscales every frame. 100% plus text scaling looks identical and is free.

Read before you run any of this. It installs a kernel-level key remapper that sees every keystroke, and can replace a system file the login screen depends on. Both are reversible, and both are documented. SECURITY.md
